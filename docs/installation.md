# Installation

## Stable release

To install Notes to X, run this command in your terminal:

```sh
uv add notes-to-x
```

Or if you prefer to use `pip`:

```sh
pip install notes-to-x
```

## From source

The source files for Notes to X can be downloaded from the [Github repo](https://github.com/Schrubitteflau/notes_to_x).

You can either clone the public repository:

```sh
git clone git://github.com/Schrubitteflau/notes_to_x
```

Or download the [tarball](https://github.com/Schrubitteflau/notes_to_x/tarball/master):

```sh
curl -OJL https://github.com/Schrubitteflau/notes_to_x/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd notes_to_x
uv pip install .
```
